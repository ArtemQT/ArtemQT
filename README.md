  <img align="right" src="https://raw.githubusercontent.com/ArtemQT/porsche-website/main/client/public/logo/porsche-logo.svg" width="120" />
</a>

**Full‑stack SPA** inspired by porsche.com — custom car configurator, JWT authentication, and personal cabinet for saving builds.

- **Tech:** React 19 · TypeScript (strict) · TanStack Query · Node.js · Express · Prisma · PostgreSQL
- **Security:** Access + Refresh JWT (httpOnly cookie), config hash deduplication
- **Architecture:** Feature‑based frontend, layered backend, full TypeScript coverage
